# Canvas Design

Use this skill to create a static visual artifact whose primary content is composition, not explanatory prose. The deliverable is usually a PNG or PDF, accompanied by a concise design philosophy when useful.

Begin with the design objective, audience, format, and any concrete constraints from the user. Then define a visual philosophy that can drive form, space, color, material, scale, rhythm, hierarchy, and typography. The philosophy should be specific enough to guide the composition but open enough to support original execution.

The user's topic should become a refined conceptual reference inside the piece rather than a literal label. A viewer familiar with the subject may recognize it through structure, proportion, palette, symbols, or visual rhythm; others should still encounter a coherent abstract or editorial composition.

## Composition Standard

Create a single-page visual object unless the user asks for a sequence. Favor spatial communication over paragraphs. Text should be sparse and treated as a visual element: a title, label, coordinate, caption, or deliberate typographic gesture. Nothing may fall off the canvas, overlap unintentionally, or crowd the edge.

Use the bundled fonts under `canvas-fonts` when typography matters. Choose typefaces for the subject and format, not because they are convenient. Use repetition, alignment, contrast, scale, texture, and negative space with discipline. If the first pass feels merely decorative, refine the existing composition rather than adding more elements.

## Visual Harness

Render the actual output before delivery. For PNG, open or inspect the produced bitmap. For PDF, render the affected page to an image before judging layout. Check dimensions, margins, clipping, overlap, text legibility, contrast, exported resolution, and whether the composition still matches the stated visual philosophy.

If the output is generated by code, do not stop at code review. Inspect the final file. If rendering is unavailable, report the exact command needed to inspect it and mark visual verification as pending.

## Output

Produce the final PNG or PDF, visual verification evidence or pending checks, and when appropriate a short Markdown file describing the visual philosophy. For multi-page work, keep the pages related by a shared system while giving each page a distinct role in the sequence.
