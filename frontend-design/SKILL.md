# Frontend Design

Use this skill when the output is a working frontend surface, not a static explanation of one. The interface should solve the user's task, fit its audience, and feel deliberately designed rather than assembled from generic component habits.

Before coding, identify the product context, the primary workflow, the intended user, and the visual tone that fits the domain. A finance dashboard, a research tool, a portfolio, and an experimental art interface should not share the same layout, typography, density, or motion language. Commit to a clear direction and make the implementation support that direction through real structure, not decorative afterthoughts.

Build production-grade code in the existing stack whenever a stack is present. Keep the first screen useful. Do not create a marketing-style landing page when the user asked for an app, tool, dashboard, or game. Use familiar controls for familiar actions, stable responsive dimensions for fixed-format UI, and accessible labels or tooltips where icon-only controls are not self-evident.

Typography, color, spacing, imagery, and motion must be chosen for the subject. Avoid default font stacks, generic purple gradients, centered hero blocks without functional content, card-heavy filler, and palettes that differ only by shade. Use real visual assets when the site or game needs them.

## Visual Harness

During implementation, establish the browser command, local URL, or file path that renders the interface. Before completion, inspect at least one desktop and one mobile viewport. Capture screenshots when tooling is available, check browser console errors, verify key interactions, confirm assets load, and check that text does not overflow or occlude other content.

For canvas, animation, or Three.js work, verify that the rendered pixels are nonblank, correctly framed, and interactive or moving as intended. Do not infer visual correctness from component code alone.

If the app cannot be run in the current environment, leave the exact command needed to run it and state which visual checks remain pending.
